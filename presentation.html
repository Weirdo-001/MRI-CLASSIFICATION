🧠 ML Model & Training Pipeline

🏗️
Transfer Learning Architecture
Base: EfficientNet-B3 (ImageNet pretrained)
Input: 300×300 MRI images
Augmentation: Flip, Rotate 15°, Zoom 15%, Contrast 10%
Training: 80-20 split, Batch 32
Phase 1: Frozen base, 30 epochs, lr=1e-4
Phase 2: Unfreeze last 50 layers, 10 epochs, lr=1e-5
Loss: Sparse Categorical Crossentropy
Optimizer: Adam (adaptive)
📈
Architecture & Performance
Classification Head:
• GlobalAveragePooling2D
• BatchNormalization
• Dense(256, ReLU)
• Dropout(0.5)
• Dense(4, Softmax)

Results:
✓ 87.5% Training Accuracy
✓ 4 Classes (Glioma, Meningioma, Pituitary, No Tumor)
✓ <1 sec Inference Time
✓ 16.9M Parameters

🔥 Explainable AI: Grad-CAM

🔍
Why Grad-CAM?
Medical AI needs transparency. Grad-CAM (Gradient-weighted Class Activation Mapping) highlights the exact regions in the MRI that led to the model's prediction, building trust with healthcare professionals by eliminating the "black box" effect.
⚙️
Technical Implementation
Extracts gradients from the top_conv layer of EfficientNet-B3. We apply a gradient tape to watch the input tensor, compute partial derivatives, apply power-normalization to emphasize the hottest activation zones, and overlay a Jet colormap on the original MRI via OpenCV/PIL.

⚡ Big Data Processing: PySpark

📈
Data Inventory & Analytics
Built a PySpark pipeline for handling large-scale medical datasets. It processes image metadata and performs exploratory data analysis (class distribution, file validation, corrupt image detection) seamlessly.
🛠️
Distributed Technical Stack
Uses Apache Spark (PySpark) with a Java (OpenJDK) backend deployed on our AWS EC2 instance. This architecture is designed to scale effortlessly if the diagnostic dataset grows from thousands of MRIs to millions, ensuring enterprise-grade scalability.
