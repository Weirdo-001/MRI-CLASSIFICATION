05 / PIPELINE
End-to-End Pipeline

Project Pipeline

From raw MRI data to live deployed prediction — 6 stages

1
Data Collection & Augmentation
Kaggle brain MRI dataset with 4 classes (Glioma, Meningioma, Pituitary, No Tumor). 80/20 train-val split, AUTOTUNE prefetch. Augmentation: RandomFlip RandomRotation(0.15) RandomZoom(0.15) RandomContrast(0.1)
2
PySpark Metadata Processing NEW
pyspark_pipeline.py — SparkSession "BrainTumorMRIProcessing", creates structured DataFrame from image metadata, runs groupBy("label").count() for class distribution, filters by class.
3
Model Training (Two-Phase)
Phase 1: EfficientNetB3 base frozen, Dense(256)+Dropout(0.5), Adam lr=1e-4, 30 epochs w/ EarlyStopping + ReduceLROnPlateau + ModelCheckpoint.
Phase 2: Unfreeze last 50 layers, lr=1e-5, 10 more epochs. Final accuracy: 87.5%
4
GradCAM Integration NEW
gradcam.py — Extracts gradients from top_conv layer via tf.GradientTape, pools gradients, produces normalized heatmap. Power-normalization (²) applied. Jet colormap overlay at α=0.55.
5
Streamlit App (app.py)
Loads tumor_model.keras via @st.cache_resource. Runs real_prediction() → calls GradCAM → renders Plotly donut chart, gauge, radar chart + 3-panel GradCAM viewer + clinical tabs (Symptoms/Treatment/Stats).
6
AWS EC2 Deployment
Code pushed to GitHub → SSH into EC2 (Amazon Linux 2023, t3.medium) → virtualenv → pip install requirements → nohup streamlit run app.py --server.port 8501 --server.address 0.0.0.0 & → Live at 98.84.64.42:8501

GradCAM — Explainable AI

Gradient-weighted Class Activation Mapping — making the model transparent

🔍
What is GradCAM?
GradCAM uses gradients flowing into the final convolutional layer to produce a localization heatmap. It highlights which spatial regions of the MRI scan drove the model's classification decision — making AI diagnoses interpretable for clinicians.
⚕️
Why Critical for Medical AI?
▸Builds clinician trust — explains the "why" behind every prediction
▸Detects model biases (e.g., attending to skull vs. tumor tissue)
▸Required for regulatory-grade AI systems in healthcare
# gradcam.py — implementation def get_last_conv_layer(model): preferred = ["top_conv", "block7b_project_conv", "block7a_project_conv"] for name in preferred: if name in layer_names: return name def get_gradcam_heatmap(img_array, model, layer): # KEY: cast to float32 BEFORE tape.watch() img_tensor = tf.cast(img_array, tf.float32) with tf.GradientTape() as tape: tape.watch(img_tensor) conv_outputs, predictions = grad_model(...) class_channel = predictions[:, pred_index] grads = tape.gradient(class_channel, conv_outputs) pooled = tf.reduce_mean(grads, axis=(0,1,2)) heatmap = conv_outputs[0] @ pooled[..., tf.newaxis] return (heatmap / max_val).numpy() def overlay_gradcam(img, heatmap, alpha=0.55): heatmap = np.power(heatmap, 2.0) # power-norm # Jet colormap → blend with original MRI
